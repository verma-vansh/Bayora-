# Security Policy

Bayora is a security tool; please report vulnerabilities privately via GitHub
**Security -> Report a vulnerability** (or email the maintainers). Do not open public issues for
undisclosed vulnerabilities. We aim to acknowledge within 72 hours.

Scope notes: the built-in `mock` model is intentionally vulnerable and its canary secret is a test
value; weaknesses in it are not vulnerabilities. See `docs/THREAT_MODEL.md` for what is in scope.
